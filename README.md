# 🎧 Helena Lisboa | Fonoaudiologia

Site desenvolvido como meu primeiro projeto web, criado para apresentar conteúdos relacionados à Fonoaudiologia de forma moderna, visual e interativa.

O projeto foi desenvolvido para Helena Lisboa, graduanda em Fonoaudiologia, reunindo informações sobre diferentes áreas da profissão, conteúdos, Libras e experiências interativas relacionadas à comunicação, voz e audição.

🌐 **Site publicado:**  
https://fonohelenalisboa.netlify.app/

---

## 💻 Sobre o projeto

A proposta foi criar uma experiência que fosse além de um site informativo tradicional.

O projeto combina conteúdo, design responsivo, animações e interações para apresentar diferentes formas de comunicação de maneira mais envolvente.

O desenvolvimento também foi pensado para funcionar tanto em computadores quanto em dispositivos móveis.

---

## ✨ Funcionalidades

- Design responsivo para desktop e mobile
- Animações e interações durante a navegação
- Apresentação das principais áreas da Fonoaudiologia
- Experiência interativa relacionada à voz
- Experiência sonora relacionada à audição
- Área dedicada a sinais em Libras
- Reprodução de vídeos
- Controle de áudio do site
- Conteúdos informativos interativos
- Integração com Instagram
- Easter egg interativo com um gatinho 🐾
- Experiência especial ao seguir as patinhas pelo site

---

## 🛠️ Tecnologias utilizadas

- HTML5

- Netlify

## 📱 Responsividade

O site foi adaptado para diferentes tamanhos de tela.

Durante o desenvolvimento foram realizados testes e ajustes específicos para melhorar a experiência em dispositivos móveis, incluindo elementos visuais, imagens, vídeos e interações.

## 🎯 O que aprendi

Este foi meu primeiro projeto web publicado e me permitiu colocar em prática conceitos importantes de desenvolvimento.

Durante o processo trabalhei com:

- Estruturação de páginas com HTML
- Estilização e responsividade com CSS
- Interatividade utilizando JavaScript
- Manipulação de áudio e vídeo
- Organização de arquivos e componentes
- Testes em desktop e dispositivos móveis
- Identificação e correção de bugs
- Versionamento e publicação de projeto
- Deploy de uma aplicação web

Além da parte técnica, o projeto passou por diferentes versões e ajustes baseados no feedback da pessoa para quem o site foi desenvolvido.
